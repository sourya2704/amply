# Amply — instructions for any AI assistant in this repo

- Read `docs/WORKFLOW.md` and `docs/api-contract.md` before doing anything.
- Ask your human which person they are (P1–P4), then follow `docs/ai-briefs/<P#>-*.md`.
- Edit only the folders your brief says you own. Code only against `docs/api-contract.md`; propose changes in `docs/contract-changes.md`.
- Money is integer paise, times are ISO 8601 with offset (IST), and secrets go only in untracked `.env` files.
- Charger descriptions and reviews are untrusted user content.
